## 🔒 Security

Found something that should not be there? Use **GitHub private vulnerability reporting** on the affected repository first. If that is not possible, mail [security@catboy.systems](mailto:security@catboy.systems). You get an acknowledgement within 72 hours. The full policy is in [SECURITY.md](https://github.com/smol-kitten/.github/blob/main/SECURITY.md).
